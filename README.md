# Snake

The classic Snake game on an HTML canvas, in a single HTML file.

## What it does
- 400x400 canvas with a 20x20 grid; the snake is green and the apple is red.
- Move with the **arrow keys**.
- Eating an apple makes the snake longer and places a new apple at a random spot.
- The snake wraps around the edges of the board.
- If the snake runs into itself, its length resets to 5.
- There is no score display or game-over screen.

## Run it
Open `snake.html` in a browser. No build step or server needed.
